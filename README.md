# Algorithm-Bonus

This repository contains various JavaScript algorithm exercises and projects. Each project demonstrates different programming concepts and problem-solving approaches. Below is a list of the included projects with a brief description of each.

## Projects

### 1. Number Guesser
A simple script that allows users to guess a randomly generated number.

### 2. Fibonacci Numbers
A script that calculates Fibonacci numbers using different approaches (iterative and recursive).

### 3. Divisors
A script to find all the divisors of a given number.

### 4. Pizza Flavors Manager
A simple web application to manage pizza flavors, built with HTML and JavaScript.

### 5. Array Sort
A script that sorts an array using different sorting algorithms.

## Getting Started
To run the scripts, clone the repository and execute the JavaScript files in a browser console or using Node.js.

```sh
# Clone the repository
git clone https://github.com/yourusername/Algorithm-Bonus.git

# Navigate into the project folder
cd Algorithm-Bonus

# Open the scripts in a browser or run them with Node.js
node script.js
```
